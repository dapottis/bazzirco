# Bazzirco
This is a quick and dirty image which combines the best of [Bazzite](https://bazzite.gg/) and [Zirconium](https://zirconium.gay/). I modified it trying to use noctalia instead of DMS.

To install, install Bazzite (preferably the GNOME image, KDE does work though), and rebase with one of these commands. 

## Regular Images
AMD/Intel image:
```
sudo bootc switch ghcr.io/dapottis/bazzirco
```

# Developer Experience (DX) images
AMD/Intel image:
```
sudo bootc switch ghcr.io/dapottis/bazzirco-dx
```
